# One Click Reload

*По-русски — ниже.*

A tiny addon for **World of Warcraft: Forever** (Interface 16001): a button on the minimap that reloads the interface with one click.

- **Click** the pocket-watch button on the minimap to reload the UI.
- **Drag** it around the minimap; the position is saved.
- **/rl** does the same from chat.

No options, no libraries, nothing running in the background. English and Russian.

## Install

Download the ZIP from [Releases](https://github.com/localhost1989/ReloadButtonForever/releases/latest), CurseForge or Wago, and extract the `ReloadButtonForever` folder into `Interface/AddOns`.

## По-русски

Маленький аддон для **World of Warcraft: Forever**: кнопка у миникарты перезагружает интерфейс одним нажатием.

- **Нажмите** на кнопку с часами у миникарты — интерфейс перезагрузится.
- **Перетащите** её вдоль миникарты — место запомнится.
- Команда **/rl** делает то же самое.

Без настроек и библиотек, ничего не работает в фоне.
